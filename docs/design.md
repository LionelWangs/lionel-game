# 刮成百亿富翁 · 设计定稿

像素风 2D 刮刮乐增量游戏。目标：用赌的刺激拉住玩家，用增量系统兜住下限，输了也解压。

工程名：Scratch to Billions。界面文案英文，金额统一 `100.000.00` 格式（千分位与小数均用点号）。

本地化：中英双语，标题页可切换并写入存档，首次启动跟随系统语言。
英文原文作为翻译 key，缺翻译自动回退；中文表在 `localization/zh_CN.po`。

## 核心数字

- 游戏唯一目标：生涯累计刮出 100 亿（100,000,000,000）
- 票面最高奖：100 万，头奖概率印在票面：1/100,000
- 单张票最大损失只有票价，永久保底，无失败结局
- 100 亿 ÷ 100 万 = 10,000 次头奖，作为终局结算的彩蛋文案

## 场景与流程

标题页（NEW GAME / CONTINUE / QUIT）→ 章节过场动画 → 游戏主场景（刮卡）
→ 菜单回标题。所有场景切换使用像素溶解转场（Bayer 抖动蒙版）。

| 场景 | 内容 |
| --- | --- |
| 标题页 | 摊位夜景、灯笼摆动、金币粒子、主菜单 |
| 过场 | 章节卡片 + 打字机字幕 + 轻微镜头漂移，可点击加速或跳过 |
| 游戏 | 刮卡、结算演出、奖池、HUD、统计 |

正式版继续补：升级商店、图鉴收集、生涯统计、结局演出。

存档：`user://save.json`，保存金额、奖池、张数与统计，标题页 CONTINUE 读取。

## 三层循环

- 秒级：拖动刮开涂层，碎屑、沙沙声、图案渐显
- 分钟级：开奖（中奖 / 差一点 / 空票），奖金演出
- 小时级：买票 → 升级刮具 → 自动刮 → 开分店 → 发行自己的彩票

## 赌徒心理机制

- 命运预定：结果在购票瞬间定死，刮只是揭晓，可复现可存档
- 差一点：输票中约 25% 出现「两连图案，最后一格不是」的假希望
- 悬念排序：奖级按小奖到大奖排列，最诱人的最后揭
- 奖池滚存：每张票抽 5% 进本期头奖池，数字实时跳动
- 保底：每 5 张必出小奖，每 50 张必出 10 倍以上
- 头奖演出：慢放 + 心跳 + 全屏动画 + 数字滚动

## 数值设计

票种按网格分档，1×1 起步，用技能 TICKET SHELF 逐级解锁到 9×9：

| 票种 | 网格 | 票价 | 中奖率 | 基础返奖率 | 头奖 |
| --- | --- | --- | --- | --- | --- |
| LUCKY CARD | 1×1 | 10 | 7% | 54% | 3.000 |
| QUAD CARD | 2×2 | 25 | 8% | 62% | 10.000 |
| NINE CARD | 3×3 | 60 | 8% | 63% | 30.000 |
| SIXTEEN CARD | 4×4 | 150 | 8% | 64% | 90.000 |
| TWENTY-FIVE CARD | 5×5 | 400 | 8% | 64% | 280.000 |
| THIRTY-SIX CARD | 6×6 | 1.000 | 8% | 67% | 1.000.000 |
| FORTY-NINE CARD | 7×7 | 2.500 | 9% | 70% | 1.000.000 |
| SIXTY-FOUR CARD | 8×8 | 6.000 | 10% | 75% | 1.000.000 |
| EIGHTY-ONE CARD | 9×9 | 15.000 | 11% | 82% | 1.000.000 |

中奖规则：1×1 刮出图案即中奖；2×2 及以上连成一条线（行 / 列 / 对角线）即中奖。
奖级倍率 ×1 / ×3 / ×8 / ×25 / ×80 / ×250 / 头奖，每档独立奖池滚存。
技能拉满后 9×9 的返奖率约 326%。

## 成长系统

每张票给 XP（票价越高给得越多），升级给 3 点技能点。九个技能把「难」逐项拆掉：

| 技能 | 效果（每级） | 满级 |
| --- | --- | --- |
| TICKET SHELF | 解锁更大的票种 | 1×1 → 9×9 |
| SHARP EDGE | 笔刷 +1 像素 | 5 → 11 |
| AUTO SCRATCH | 自动刮 +1.8%/秒 | 满级全自动清屏 |
| LUCKY FINGERS | 中奖率 +0.6% | +6% |
| GOLDEN TOUCH | 赔付 +8% | ×1.8 |
| FRUGAL GUY | 票价 -3% | ×0.7 |
| JACKPOT FEED | 奖池每张 +50 | +500 |
| SOFT LANDING | 差一点补偿 +20 | 200.00 |
| MENTOR | XP +10% | ×1.5 |

保底与兜底：连输 7 张必出小奖；没钱送免费票；1×1 票前三张保底中奖。

## 里程碑与终局

1 万 → 100 万（第一次头奖）→ 1,000 万 → 1 亿（反转成店主）→ 10 亿 → 100 亿。

终局演出：最后一格慢放，刮开后金币海啸、屏幕震动、自适应音乐全奏，数字从亿滚到百亿定格，随后弹出结算册与彩蛋卡片。

## 视觉风格

- 16-bit 彩色像素，红金国潮 + 纸白留白 + 青瓷绿点缀
- 票面拟真：纸纤维、银粉涂层用抖动纹理、烫金、防伪纹、票根条码
- 世界卡通：路边摊 → 小店 → 连锁店 → 彩票帝国，靠调色板和光影换皮
- 吉祥物：招财猫（流浪猫 → 店猫 → 店长 → 机械猫军团）
- 内部分辨率 640×360，整数倍缩放，最近邻采样，像素吸附

## 技术要点

- Godot 4.7（.NET 版），纯 GDScript 实现，PC 桌面优先，兼容触屏
- 刮除：4×4 像素块蒙版擦除 + 抖动纹理涂层 + 像素碎屑
- 结果预生成：购票时用 RNG 生成票面与奖项，存档只需存结果
- 移动端：横屏 + 整数缩放 + `keep` 宽高比；触摸与鼠标双输入；装饰性控件不吞输入
- 音频：程序合成（刮擦白噪音、金币、号角），BGM 为芯片音乐 + 五声音阶
  （方波主旋律 / 三角波贝斯 / 噪声打击），标题与游戏各一首，无缝循环
- 字体：缝合像素字体 12px（OFL），版权文件随资源保留

## 素材来源

- itch.io / OpenGameArt（CC0/CC-BY）：像素素材候选

## MVP 范围（当前）

一张票、一根手指、一个中奖瞬间：手刮涂层 → 三连图案派奖 → 差一点 / 大奖反馈 → 奖池计数器 → 空格买下一张。
